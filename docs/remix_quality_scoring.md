# 成片预览质量评分与风险提示方案

## 背景

Business 页面里的“成片预览”用于给剪辑人员快速判断多个混剪方案是否可用。此前方案只展示视频和口播文案，剪辑人员需要完整预览后才能发现问题，例如：

- 混入主播回复直播间观众的互动内容
- 混入其他链接、其他款、非主品描述
- 开头像直播中途截断，语义不完整
- 缺少促单收尾
- 卖点覆盖不足
- 时长偏离目标

因此需要在方案生成后自动给出质量评分和风险标签，让剪辑人员先排雷，再看视频。

## 当前落地范围

当前实现为规则评分，不依赖额外 LLM 调用，避免增加生成耗时和接口成本。

主要改动：

- `src/autocut/remix.py`
  - 新增 `score_remix_plan(plan, request, target_duration)`。
  - 根据方案文案、片段角色、时长、主品信息输出质量评分。
- `src/autocut/business_api.py`
  - 生成 remix 方案时写入 `quality`。
  - 老任务打开详情时，如果 plan 中没有 `quality`，从 plan JSON 回算。
- `src/autocut/static/business.js`
  - 成片预览卡片展示质量分、风险标签、风险说明。
- `src/autocut/static/business.css`
  - 增加评分胶囊、风险标签、风险说明样式。

## 输出结构

每个 remix plan 会包含：

```json
{
  "quality": {
    "score": 86,
    "level": "warn",
    "summary": "基本可用",
    "risks": [
      {
        "type": "opening",
        "label": "开头不完整",
        "severity": "medium",
        "message": "第一句承接句/可能缺少前文。",
        "penalty": 18
      }
    ],
    "metrics": {
      "duration": 24.6,
      "item_count": 5,
      "close_count": 1,
      "selling_count": 3,
      "target_term_hits": ["哈利波特透明伞", "学院风设计"]
    }
  }
}
```

## 评分等级

| level | summary | 含义 |
|---|---|---|
| `good` | 质量较好 | 未发现明显风险，分数较高 |
| `warn` | 基本可用 | 有轻中度提示，建议快速看一遍 |
| `risk` | 建议复核 | 存在高风险或分数较低，剪辑人员需要重点检查 |

当前分数从 100 开始，根据风险扣分，最低为 0。

## 风险规则

### 高风险

| type | label | 触发条件 | 处理建议 |
|---|---|---|---|
| `price` | 价格风险 | 文案包含具体价格、到手价、直播价、金额等 | 不建议投放，需替换片段 |
| `interaction` | 直播互动 | 文案包含回复观众、公屏、弹幕、客服、私信、扣字等直播互动 | 不建议出现在成片中 |
| `other_product` | 疑似非主品 | 文案疑似提到其他链接、其他款、其他产品，并且没有命中主品词 | 需要重点复核是否混入其他产品 |

### 中风险

| type | label | 触发条件 | 处理建议 |
|---|---|---|---|
| `opening` | 开头不完整 | 第一条像承接句、半句话、缺少前文 | 检查是否适合作为短视频开头 |
| `close` | 缺少促单收尾 | 没有售后、活动、送礼、下单理由等 close 片段 | 建议补促单句 |
| `selling_points` | 卖点偏少 | 中段卖点、场景、工艺片段不足 | 建议补卖点或换方案 |
| `target_match` | 主品命中弱 | 文案没有明显命中主品、品牌热词或卖点词 | 检查是否偏离当前产品 |

### 低风险

| type | label | 触发条件 | 处理建议 |
|---|---|---|---|
| `duration_short` | 时长偏短 | 低于目标时长下限 | 可能信息量不足 |
| `duration_long` | 时长偏长 | 超过目标时长上限 | 可能节奏偏拖 |

## 前端展示

成片预览卡片展示三层信息：

1. 标题行
   - 方案名称
   - 质量分，例如 `92分 · 质量较好`
   - 时长

2. 风险标签区
   - 没有风险时显示 `未发现明显风险`
   - 有风险时展示最多 5 个标签

3. 口播文案区
   - 展示完整口播文案
   - 底部展示最多 4 条风险说明

## 老任务兼容

老任务的 `job.json` 中可能没有 `script_text` 或 `quality`。

兼容逻辑：

- 接口返回任务详情时读取对应 plan JSON。
- 如果缺少 `script_text`，从 plan `items` 拼接。
- 如果缺少 `quality`，调用 `score_remix_plan()` 回算。

这样老任务不需要重新生成，也能看到口播文案和质量提示。

## 后续升级方向

1. **LLM 二次质检**
   - 在规则评分后，对 `warn/risk` 方案调用 LLM 复核。
   - 输出更自然的质检说明，例如“第 2 句疑似回答观众问题”。

2. **风险阈值配置化**
   - 将扣分、时长窗口、风险严重程度做成配置。
   - 不同业务线可以调整标准。

3. **人工反馈闭环**
   - 剪辑人员标记“可用/不可用/误报”。
   - 后续用反馈优化规则或训练轻量分类器。

4. **逐句风险定位**
   - 当前风险是方案级。
   - 后续可以在每条口播旁标注风险，快速定位具体问题句。

5. **主品一致性增强**
   - 给每个 ASR unit 增加 `target_match_score`。
   - LLM prompt 只优先展示高可信主品句，低可信句放参考区。
