# 0004 - 切片质量微调：价格过滤 + 结尾裁剪 + 衔接优化

- **状态**: done
- **创建日期**: 2026-05-14

## 背景

当前切片效果存在以下问题（用户反馈）：

1. 结尾比重过长，片段末尾存在大量无效内容
2. 音频中含有价格信息（违规），需要过滤掉
3. 片段衔接处存在上一句"半个字"的残留噪声

③④（卖点前置、结构化3-5卖点）通过 LLM remix prompt 优化，不在本 proposal 范围内。

---

## 目标

| 编号 | 改进项 | 预期效果 |
|---|---|---|
| ⑤ | 价格内容自动过滤 | 含价格的 segment 打标并在导出时静音或剔除 |
| ② | 结尾裁剪 | 片段末尾的语气词、无实意内容裁掉，缩短 end_time |
| ⑥ | 衔接边界优化 | 开头加前置缓冲（-50ms），结尾加后置缓冲（+80ms），避免切到字中间 |

---

## 方案

### ⑤ 价格过滤 — `cleaning.py`

新增价格正则 `PRICE_PATTERNS`，在 `clean_text` 函数中检测，命中时追加 `invalid_reasons: ["contains_price"]`。

需要覆盖的场景：
- `数字 + 元/块`（如"99元"、"59块"）
- `数字 + 折`（如"八折"、"8折"）
- `原价/现价/促销价/特价/到手价/券后 + 任意字符`
- `X件Y折`、`买X送Y`

处理方式：将价格相关的文字从 `clean_text` 中抹掉（替换为空），类似水词处理；同时保留原始 `text` 不动（用于调试）。

---

### ② 结尾裁剪 — `cleaning.py` 新增 `trim_trailing_fillers`

参照 `trim_leading_fillers` 反向实现：

1. 取候选片段最后一个 `segment_index` 对应的 segment
2. 从其 `words` 列表**从后往前**遍历
3. 跳过结尾连续的语气词（复用 `_is_leading_filler_word`）
4. 找到最后一个非水词，将 `candidate.end_time` 更新为该词的 `end` 时间

额外：若片段结尾超过 `end_padding_ratio`（默认 15%）的时长内没有关键词命中，也按比例收缩 `end_time`（此项可选，作为参数控制）。

---

### ⑥ 衔接边界缓冲 — `cleaning.py` 的 `trim_leading_fillers` + 新增 `trim_trailing_fillers`

- 开头：`candidate.start_time = max(0, new_start - 0.05)` （当前是直接赋值为 word start，去掉 `+0.05` 改为 `-0.05`）
- 结尾：`candidate.end_time = last_word_end + 0.08`

两个 padding 值作为参数暴露，方便后续调整。

| 文件 | 改动 |

| `src/autocut/pipeline.py` | 在 `trim_leading_fillers` 调用后，追加 `trim_trailing_fillers` 调用 |
| `src/autocut/models.py` | 检查 `invalid_reasons` 是否已支持扩展（应该已支持） |

---

## 验收标准

1. **价格过滤**：含"99元"、"8折"、"到手价"、"买一送一"的 segment，其 `clean_text` 中对应文字被清除，`invalid_reasons` 含 `"contains_price"`
2. **结尾裁剪**：候选片段最后一个词为语气词时，`end_time` 收缩到前一个实意词的 `end` 时间
3. **边界缓冲**：开头 `start_time` 比第一个实意词提前 50ms，结尾 `end_time` 比最后一个实意词延后 80ms
4. **不破坏现有流程**：所有现有测试通过，`pipeline.py` 整体 run 无报错
